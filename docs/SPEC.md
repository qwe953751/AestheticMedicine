# 功能規格與驗收

## 0.2（2026-11-09）最新需求與驗收

使用者要求照片預覽、整份報告線上預覽及跨裝置讀取，並授權實作、文件、commit、push、發佈。另確認在 Frank 組織新建獨立 AestheticMedicine 後端，報價 US$0／月。

- 照片選檔顯示縮圖及可操作大圖預覽；不能保存沒有圖片的新照片紀錄。
- PDF 預覽所有頁面、可縮放、可捲動至最後一頁；圖片報告可放大，PDF 密碼只用當次。
- 空報告需補附件、連結或手動指標；舊 0 附件紀錄不虛構補檔，需使用者重新上傳。
- 註冊驗證、同帳號登入後讀取相同雲端紀錄與附件；未登入資料保持本機，舊資料需明確上傳。
- 本機加入雲端保留未衝突紀錄，不同內容同 ID 不覆蓋；雲端寫入以 revision 防止跨裝置覆蓋。
- 私人附件禁止匿名、跨帳號及公開網址讀取；保持唯一正式網址與其他空白入口規則。
- Cloud 與原始 PDF／照片預覽不代表 AI／OCR／外部報告自動解析已完成。

以下第一版內容為歷史驗收，與上述 0.2 衝突時以上述及 README／ARCHITECTURE 為準。

## 需求承接

2026-11-08 使用者明確授權開始實作、更新文件、commit、push 及發佈網站，取代交接文件的「先不實作」限制。既定需求為個人使用、手機與電腦皆可操作，串聯療程結果、照片、檢測報告、保養與行事曆。

Repository 原有 README 指定 GitHub Pages，既有正式網址已存在。因此第一版沿用靜態網站，以本機資料保存與手動備份提供可立即使用的功能。此為本次實作選擇，**不代表帳號及雲端同步已完成，也不把先前 Agent 的規劃建議視為使用者確認**。

## 頁面與行為

| 頁面 | 使用行為 | 空資料時 |
| --- | --- | --- |
| 總覽 | 統計、最近紀錄、即將追蹤、快速新增療程與日誌 | 真實空狀態，不預填虛構膚況 |
| 療程與日誌 | 分類、搜尋、查看、編輯、刪除；日期由新到舊 | 提供新增入口 |
| 照片追蹤 | 上傳、階段、角度、關聯療程；任選兩張照片並排；顯示距療程天數 | 不放示例人像 |
| 檢測報告 | 來源連結、原始附件、手動指標；摘要檢視及下載 | 說明自動匯入尚未支援 |
| 保養與諮詢 | 產品與時段、醫囑、固定諮詢清單 | 提供建立保養步驟入口 |
| 行事曆 | 切月、選日、新增日程、完成或取消完成、ICS | 以台北當日為預設 |
| 資料與設定 | 儲存方式、限制、全量備份、驗證後匯入 | 可匯出空備份 |

## 驗收條件

- 新增紀錄後統計與列表同步更新；重新整理能重新讀取。
- 必填標題與日期需驗證。費用不得為負數；來源只接受 HTTP(S)，不接受內嵌帳密 URL。
- 附件限制數量、大小、MIME 與基本檔頭；不接受 SVG、HTML 或可執行檔。
- 照片可關聯療程，並排顯示任選附件；不直接分析、診斷或宣稱因果。
- 報告保留人工核對的原始數值與量尺；不因缺漏而自動補值。
- 摘要標示資料是手動輸入，未讀取外部連結或附件，未執行 AI。
- 本機備份含完整紀錄與附件；拒絕不支援版本、損毀欄位、重複 ID、遺失關聯與危險連結。
- 匯入會顯示各類筆數與取代提示，提供先備份的入口，確認後以單次交易取代。
- 刪除前確認；刪療程會保留其他紀錄並解除關聯。
- 月曆以週一為首日；支援閏年及跨年。日程以台北時間輸入，ICS 有時間時轉 UTC，全天保留日期。
- 舊分頁不得覆蓋新分頁資料；儲存失敗不關閉表單。
- 手機收合導覽、表單、照片比較及月曆可操作；對話框具鍵盤焦點限制與 Escape 關閉。

## 分階段待辦

1. 私人帳號、後端授權、照片雲端儲存、跨裝置同步與草稿、刪除／備份策略。
2. 驗證 EveLab 官方介接或匯出方式；登入或密碼限制下的人工確認流程，不能承諾任意連結可讀。
3. PDF／截圖擷取與逐欄核對；儀器及量尺相容性規則。
4. 明確取得使用者選擇後，才規劃向外部 AI 傳送哪些資料與照片。
5. 經確認的個人化保養／諮詢摘要與追蹤建議；外部提醒與日曆同步。

原交接文件內的私人報告 URL 與密碼未複製到本 repository，也未用作網站種子資料。
